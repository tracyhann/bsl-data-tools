# Data Resource Tools

Small utilities for preparing, cleaning, and navigating study data resources.

| Tool | What it does |
| --- | --- |
| [Folder Navigator](folder-navigator/README.md) | Turns a Google Drive folder link into a clickable directory tree. |
| [Create Study Folder in Google Drive](create-study-folder-gdrive/README.md) | Publishes a cleaned local study folder into a Google Drive template. |
| [GENEActiv 1.1 CSV Curator](geneactive/v1-1-csv-curator/README.md) | Splits a raw GENEActiv 1.1 CSV export into structured metadata and sensor data files. |

Each tool README includes a quick start and usage notes. Colab-based tools also include notebook links.
